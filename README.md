# Ranking Website — Full-Stack List Creation & Sharing App

A full-stack web application for creating, managing, and sharing ranked lists. Users can create multiple types of lists, such as **tier lists** or **numbered rankings**, and dynamically track and visualize items.

## Features
- Create and manage **tier lists** or **numbered lists**  
- Dynamic, interactive list visualization  
- Shareable links for each list
- Real-time updates and smooth frontend interactions

## Tech Stack
- **Backend:** C#, .NET, AWS Lambda, DynamoDB  
- **Frontend:** React, TypeScript, TanStack Query, Tailwind CSS, shadcn/ui  
- **Architecture:** Serverless RESTful API for persistent, scalable storage  

## Key Highlights
- **Full-Stack Functionality:** Built a platform supporting multiple list types with dynamic creation, tracking, and visualization of ranked items.  
- **Cloud-Native API:** Architected RESTful endpoints in C# on AWS Lambda with DynamoDB for persistent and horizontally scalable storage.  
- **Modern Frontend:** Developed a React/TypeScript frontend using TanStack for data fetching and routing, Tailwind CSS for responsive layouts, and shadcn/ui components for consistent, accessible styling.  
- **Reliable Client-Server Communication:** Established request validation, structured error handling, and consistent API response contracts for robust interactions.
